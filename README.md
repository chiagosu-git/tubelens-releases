# 튜브렌즈(TubeLens) — 판 파일

유튜브 분석 앱 튜브렌즈의 **설치 파일과 업데이트 채널**만 두는 곳입니다(앱 코드는 여기 없습니다).

- 급상승 대시보드 · 키워드 분석 · 제목 고르기 · 썸네일 문구와 사람이 나오는 썸네일 그림
- Windows 10/11 · 64비트

## 받기

[최신 판(Releases → Latest)](../../releases/latest)에서 `TubeLens-<판>-win-x64.zip` 을 받아 압축을 풀고 `TubeLens-<판>.exe` 를 켭니다.

## 업데이트

앱이 켜진 뒤 30초, 그 뒤 6시간마다 이곳의 `channel.json` 을 읽어 새 판을 뒤에서 받습니다.

- `channel.json` 은 Ed25519 로 서명돼 있고, 앱에 들어 있는 공개 열쇠로 확인됩니다. 서명이 맞지 않거나 zip·exe 해시가 다르면 받지 않습니다.
- 새 판은 먼저 켜 보고, 화면이 실제로 뜬 것을 확인한 뒤에만 넘어갑니다. 못 켜지면 지금 판을 그대로 씁니다.
- 앱 오른쪽 위의 판 번호를 누르면 업데이트 창이 열립니다(지금 확인 · 자동 받기 켜고 끄기).
